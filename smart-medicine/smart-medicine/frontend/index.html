Local data & settings

Your data is stored on the app's server and is tied to a private key saved in this browser. If you clear this browser's site data, you lose access to it, so export a backup regularly. Opening the site on another device starts an empty workspace until login is added.

Privacy tip: use this demo with sample information only on a shared computer. Exported backups contain the information you entered. No medical advice or dose recommendations are provided.

About this demo

Static frontend on Netlify talking to a Spring Boot REST API. No API keys or passwords exist in this page.

Still to come: user login, push notifications that work when the page is closed, and live pharmacy availability from a real data source.
